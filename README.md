# Task Tracker API

Пет проект бэкенда на FastAPI. Трекер задач и привычек со стриком, как в Duolingo, только для повседневных дел. Делаю его пока учусь на бэкенд разработчика, чтобы было что показать на собеседовании.

## Что умеет

Можно зарегистрироваться и залогиниться через JWT. Можно создавать и удалять обычные задачи. Можно создавать привычки, это повторяющиеся задачи, и для них каждый день сам создается новая задача автоматически. Есть подсчет стрика, то есть сколько дней подряд все задачи были выполнены. Все покрыто тестами на pytest. MySQL поднимается в докере, отдельно ставить не надо.

## Стек

Python 3.14, FastAPI, SQLAlchemy, MySQL 8.0, Pydantic v2, JWT через python jose, bcrypt для паролей, pytest для тестов, все в докере.

## Архитектура

Разбил проект на слои, как учат делать в реальных проектах. Роут принимает запрос и отдает ответ, сам ничего не решает. Сервис это вся бизнес логика и проверки. Репозиторий единственный кто трогает базу напрямую. Модель просто описывает таблицу. Так удобнее тестировать логику отдельно от базы, и легче поменять что то одно, не задев остальное.

## Структура папок

В app/api/routes лежат сами эндпоинты, разбитые по темам auth tasks habits. В app/api/dependencies.py собираются сервисы и проверяется токен юзера. В app/core лежит конфиг из .env и подключение к базе. В app/models модели таблиц, в app/schemas пидантик схемы для запросов и ответов, в app/repositories работа с базой, в app/services бизнес логика. app/main.py это точка входа. Тесты лежат в tests, там же conftest.py с тестовой базой в памяти.

## Как запустить

Нужен Python 3.11 или новее и Docker Desktop. Клонируешь репу, заходишь в папку. Создаешь файл .env в корне, туда пишешь DATABASE_URL для подключения к mysql и SECRET_KEY, любую случайную строку. Дальше поднимаешь базу командой docker-compose up -d. Создаешь виртуальное окружение, активируешь его, ставишь зависимости из requirements.txt. Запускаешь сервер командой uvicorn app.main:app --reload. После этого можно зайти на localhost:8000/docs, там свагер со всеми эндпоинтами, все можно потыкать прямо в браузере.

## Тесты

Запускаются командой python -m pytest -v. Гоняются на отдельной базе sqlite в памяти, реальную MySQL не трогают вообще.

## Эндпоинты

POST /auth/register регистрирует нового юзера. POST /auth/login логинит и возвращает токен. GET /tasks/ отдает список задач юзера, заодно проверяет и создает задачи на сегодня по активным привычкам. POST /tasks/ создает обычную задачу. PATCH /tasks/{task_id}/complete отмечает задачу выполненной. DELETE /tasks/{task_id} удаляет задачу. GET /tasks/streak отдает текущий стрик. POST /habits/ создает привычку. GET /habits/ отдает список привычек. Все эндпоинты кроме auth требуют токен в заголовке Authorization.
