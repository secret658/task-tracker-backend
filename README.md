# Task Tracker API

Пет проект бэкенда на FastAPI. Трекер задач и привычек с системой стриков, для повседневных дел.

Делаю его пока учусь на бэкенд разработчика, чтобы было что показать на собеседовании.

## Что умеет

- Регистрация и логин через JWT
- Создание и удаление обычных задач
- Привычки (повторяющиеся задачи), для них каждый день сам создается новая задача
- Подсчет стрика, сколько дней подряд все задачи выполнены
- Покрыто тестами (pytest)
- MySQL поднимается в докере

## Стек

Python 3.14, FastAPI, SQLAlchemy, MySQL 8.0, Pydantic v2, JWT (python jose), bcrypt для паролей, pytest для тестов, все это в Docker.

## Архитектура

Разбил проект на слои, как учат делать в реальных проектах:

```
Route -> Service -> Repository -> Model
```

Роуты просто принимают запрос и отдают ответ, ничего не решают сами. Сервисы это вся логика (проверки, бизнес правила). Репозитории единственные кто трогает базу напрямую. Модели это просто описание таблиц.

Так удобнее тестировать логику отдельно от базы и легче менять что то одно, не трогая остальное.

## Как запустить

Нужен Python 3.11+ и Docker Desktop.

Клонируешь репу:
```bash
git clone https://github.com/secret658/task-tracker-backend.git
cd task-tracker-backend
```

Создаешь файл `.env` в корне:
```
DATABASE_URL=mysql+pymysql://root:rootpassword@localhost:3306/tasktracker
SECRET_KEY=любая случайная строка
```

Поднимаешь базу:
```bash
docker-compose up -d
```

Ставишь окружение и зависимости:
```bash
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Запускаешь сервер:
```bash
uvicorn app.main:app --reload
```

Дальше идешь на [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs), там Swagger со всеми эндпоинтами, можно потыкать прямо в браузере.

## Тесты

```bash
python -m pytest -v
```

Тесты гоняются на отдельной базе в памяти, реальную MySQL не трогают.

## Эндпоинты

| Метод | Путь                       | Что делает |
|---    |--   -                      |--         -|
| POST  | `/auth/register`           | регистрация |
| POST  | `/auth/login`              | логин, возвращает токен |
| GET   | `/tasks/`                  | список задач (заодно создает задачи на сегодня по привычкам) |
| POST  | `/tasks/`                  | создать задачу |
| PATCH | `/tasks/{task_id}/complete`| отметить выполненной |
| DELETE| `/tasks/{task_id}`         | удалить задачу |
| GET   | `/tasks/streak`            | текущий стрик |
| POST  | `/habits/`                 | создать привычку |
| GET   | `/habits/`                 | список привычек |

Все кроме auth требуют токен в заголовке Authorization.
